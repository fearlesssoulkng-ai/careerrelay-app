Run 24/7 with GitHub Actions (Free)

Put job_watcher.py, your downloaded config.json, and your PDF CVs in a private GitHub repo, add CAREERRELAY_APP_PASSWORD in Repository Secrets, and add .github/workflows/careerrelay.yml: 

name: CareerRelay Hourly Watcher
on:
  schedule:
    - cron: "0 * * * *"
  workflow_dispatch:
jobs:
  watch:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.11"
      - name: Run one check cycle
        env:
          CAREERRELAY_APP_PASSWORD: ${{ secrets.CAREERRELAY_APP_PASSWORD }}
        run: python3 -c "import job_watcher; job_watcher.run_once(job_watcher.load_seen_ids())"
